#  Wheels on Fire
### Premium Car Showroom Website

**Wheels on Fire** is a first-semester university project developed as part of the Introduction to Information and Communication Technology (ICT) course.

It is a premium car showroom website designed to provide visitors with an attractive and user-friendly platform to explore luxury, sports, and performance vehicles.

The website presents different car collections along with essential vehicle information through a modern and visually appealing interface.

---

##  Project Overview

Wheels on Fire aims to create a digital showroom experience where users can explore different vehicles, learn about the showroom, and discover its services.

The website focuses on clean design, easy navigation, and an engaging user experience.

##  Key Features

- **Home Page:** An attractive landing page introducing the showroom.
- **About Us:** Information about the showroom and its vision.
- **Car Inventory:** Explore different vehicles and their details.
- **Featured Vehicles:** Highlights selected premium cars.
- **Services:** Information about the services offered by the showroom.
- **Contact Us:** Contact information and a dedicated contact section.
- **Responsive Navigation:** Easy navigation between different website sections.
- **Modern UI:** Premium design with attractive visuals, typography, and styling.

##  How to Run the Project

Follow these steps to run the website locally:

1. Download or clone this repository.
2. Extract the project folder if downloaded as a ZIP file.
3. Open the project folder in Visual Studio Code.
4. Open `index.html` in your browser.
5. Explore the different sections of the website.

Alternatively, use the Live Server extension in Visual Studio Code for a better development experience.
